# MemoryX

Interactive product demo: a timeline of memories and two distinct games — recall known memories and reconstruct missing periods. French and English, responsive standalone HTML.

All people, events and connected-source clues in this demo are fictional. This is not a medical tool. No AI service, account login, email, calendar, WhatsApp connection or real sharing is implemented. Changes are stored only in this browser's localStorage. Do not enter sensitive personal data. Reset demo in My rhythm to clear demo state.

Open `index.html` locally or serve it with `python3 -m http.server 8000`. The GitHub Pages deployment publishes this demonstration only, not a production service.
